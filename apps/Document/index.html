Quy trình Gửi & Nhận files

Khi làm việc chung với nhiều bên khác nhau, sẽ cần trao đổi Files qua lại, cần những lưu ý sau:

Team ES chủ yếu dùng Blender, nên sẽ ưu tiên nhận file Blender (pack resource và những file liên quan).

Nếu bên khác không sử dụng Blender, thì ES có thể nhận file FBX hoặc C4D. Cần chắc chắn đúng UV và đủ Textures.

Khi nhận file FBX hoặc C4D, team ES sẽ cần thêm thời gian để xử lý và shading, lookdev lại. Yêu cầu các bên gửi hình rendered để team tiện so sánh (Vì khác phần mềm nên kết quả sẽ có chút khác biệt <=10%)
